## §1 通道路由：先判脚本通道，再探生产链，最后 UI input（顺序不可跳）

**第 1 步 · 脚本注入通道判定**：从工程源码现查登录机制（`nl -ba` 原文行进 evidence）。
关键判据——**分清「构建期常量」vs「运行时注入」**：构建期变量（本仓例：`isE2E()` = 构建期
`VITE_E2E_BASE_URL`，`src/services/e2eMode.ts:14-16`）对**已安装的 release APK 恒无效**；
e2e 测试账号随机生成（`e2e-real/helpers/backend-api.ts:3-10`）与 mock 假值
（`e2e-real/stocks.spec.ts:22`）都只活在 Playwright 测试进程里。⇒ 已装机产物无脚本注入通道，
这是可引用源码行证明的技术事实，不是「没找到」。

**第 2 步 · 生产链可达性预探**（真实 UI 登录必然走生产后端，先证链路活着）：
- App 发现链：`src/App.tsx:354` `discoverEndpoints()` → `src/services/discovery.ts:210`
  （CF Worker `ca.huanvae.cn/endpoints`）+ `discovery.ts:35-41` BUILT_IN_DEFAULTS 兜底 IP；
- mTLS：edge nginx 要求客户端证书，App 侧 `src-tauri/src/secure_net.rs:28-35` 编译内置
  客户端证书、数据面自动呈递。宿主机**裸** curl 得 `400 No required SSL certificate was sent`
  是 mTLS 要求的表现，**不是「链路不通」**——模拟 App probe 应带仓库内证书文件路径
  （内容零回显）：`curl -sk --cert src-tauri/resources/app-client.cert.pem --key …/app-client.key.pem https://<兜底IP>/health`
  （R11 实测 HTTP=200 "OK"，evidence-shot-r11.txt:54-55：:54=命令、:55=输出行）。

**第 3 步 · UI input 通道授权判据**：卡面**明文授权**（R11 卡原文「若无脚本通道，用 adb shell
input tap/text 在 fx 上走真实 UI 登录」）才走；卡面没写时先上报扩卡，**不要自行脑补红线，
也不要自行脑补授权**。

> 凭据」+「不注册真后端新账号（**越权写状态**，自造措辞）」并列作 GAP 理由——但「注册测试账号=越权」

## §2 真实 UI 注册/登录全步骤配方（R11 实测；坐标以本轮 dump 现查为准，禁抄历史值）

0. **现状现查**（打点 date -u）：`adb devices -l`（红线机只列出零操作）→
   `dumpsys window | grep -E 'mCurrentFocus|mFocusedApp'` 定前台 →
   `uiautomator dump` 全文落 evidence 定当前停驻页（登录页/注册页/主界面的文本特征先从
   Register.tsx/Login 页面源码拿）。
1. **随机凭据生成**（值零回显，落 /tmp 不入仓）：
   ```console
   $ umask 077 && mkdir -p /tmp/<块短名> && { echo "USER_ID=ta${R}uv"; echo "NICK=uv${R}n"; \
       echo "PASS=$(openssl rand -hex 8)"; } > /tmp/<块短名>/creds.sh \
     && chmod 600 /tmp/<块短名>/creds.sh && ls -la /tmp/<块短名>/creds.sh
   ```
   生成命令以 `$()` **未展开模板**形式落档——运行时才展开，值不可回推（这是合规落档形态，
   见 §3）。随机性用时间尾段/openssl，禁用可猜值。
2. **逐框输入循环**：`uiautomator dump` 取输入框 `bounds="[x1,y1][x2,y2]"` → 中心点
   `input tap` → `input text $VAR` → `input keyevent 111`（ESC 收键盘防遮挡）→ 下一框。
   两步注册表单（本仓 `Register.tsx`：步骤1 账号/昵称→下一步；步骤2 密码/确认→注册）逐框走。
3. **提交与弹窗**：提交按钮中心 `input tap` → 系统权限弹窗（本例 GrantPermissionsActivity
   通知权限）→ 点 Allow → **注册成功自动登录**（本仓 `App.tsx:365-366`）。
4. **登录态确认**（截图的前置）：`dumpsys` mCurrentFocus 仍 MainActivity +
   `uiautomator dump` 出登录态标识（「ID: <redacted>」用户标识、底部导航「消息/通讯录」bounds）
   → 与 §4 双证标准对表后才截主界面。
5. **已知坑**：①dump 报 `null root node` = UI 过渡态瞬时，等 1-2s 重 dump；②截图/审计命令
   的 cwd 相对路径**重复前缀**（已在目录内又写全前缀）→ `No such file or directory` rc=1/
   grep rc=2——失败记录**如实留档未删改**，再修正重跑（R11 §5/§8 先例）；③历史坐标
   （R10-6 的 654,1538 等）仅对同分辨率同页面有效，**每轮 dump 现查中心**，禁凭上轮记忆 tap。

## §3 凭据零明文：操作面五律 + 审计面三路

**操作面五律**（R11 全过，红线核心=明文密码零回显）：
1. 生成命令落档为**未展开模板**（`$(openssl rand -hex 8)` 运行时展开，落档值不可回推）；
2. 凭据文件 `0600` + `/tmp/<块短名>/` + **内容零读取**（审计只用 `stat -c '%a %s'`，R11 实测
   `600 54`）；
3. 命令行/交付/台账全部 `$USER_ID/$NICK/$PASS` 变量引用，`source` 读入不打印；
4. dump 中密码字段 `type=password` 仅圆点（`••••…`），明文值零出现；
5. **界面自然回显的非密码标识**（user_id/昵称，dump 必然含）= 无保密性但须**双处披露**（交付
   +台账）且正文以 `<redacted>` 指代——「没披露」与「明文密码」是两种违规，前者是漏披露。

**审计面三路**（交付里主张「零明文」时的最低证据形态，R11 §8c/复核点③ 形态）：
1. `grep -c 'PASS='` 全 evidence/交付/台账：预期**零处明文值**；有命中则**逐行归因**
   （未展开命令模板/审计命令头自身文本/描述文字三类皆合规，值类命中即违规）；
2. 独立口令形 token 扫描 `grep -nE '\b[0-9a-f]{16}\b'`（`openssl rand -hex 8` 之形）：预期零命中；
3. `grep -nE 'input text '` 逐条核对：全为变量引用形式，无一条字面值。

## §4 页面证据双证标准 + 沿用件抽样复证

- **PNG 三证**：`file`（PNG 头+分辨率）+ `stat`（字节数+mtime）+ `sha256sum`，命令原文+完整
  输出进交付；命名带 UTC 时间戳（如 `20260907T102206Z-main.png`）。
- **目检**：亲读 PNG，核对页面语义元素（本例：消息列表+底部导航）与**状态栏时刻和截图打点
  吻合**——防「旧图新名」。
- **UI 层级支撑**：dumpsys mCurrentFocus + uiautomator dump 关键节点原文（登录态用户标识/
  导航 bounds）；**非顶替判定**=对照读「要求页面」与「手头页面」的 dump/截图（R11 复核点①：
  注册页遗留态 dump vs 登录态 dump，页面截然不同）。
- **沿用件抽样复证**（前驱截图沿用时）：首/中/尾**确定性**抽样（mtime 最旧/最新/关键核验件），
  每件现场 file+stat+sha256 与前驱**在档值**逐字节恒等——禁凭文件名脑补内容。
- 截图重复/失败路径：失败记录留档（rc=1），修正后重截，两段都进 evidence。

## §5 GAP 如实记录三件套（验收允许「或 GAP」时的唯一合规写法）

**三件套**（缺一即不构成如实 GAP）：
1. **当前停留页截图**（§4 三证标准，如实呈现停在哪页）；
2. **logcat 尾部**：`adb -s <serial> logcat -d -t 200` 原文（崩溃/网络拒绝的现场证据）；
3. **缺口清单**：缺什么、卡在哪一步、证据路径、**前置条件**（什么到位后可重试）。

**台账行式先例**（ledger.md R8-8/R9-6/R10-7）：
`<UTC打点> | <轮次-序号> 主界面(登录后) | GAP(如实上报) | 现查结论+零命中证据+前置条件 | <evidence路径>`
——结论行自带「零命中」的可复跑 grep 口径与 file:line，不写「没找到」裸结论。

**前置条件本身要可证**：R8-R10 三轮 GAP 行写「前置=测试后端+种子账号或 owner 凭据机制」——
R11 证明**随机凭据+真实 UI 注册**即可，该前置列窄了。写前置条件时同样过 §1 的三类前提检验。

## §8 WebView 装机实测：dump 全 DOM 特性与 bounds 取坐标法（块 `1788779617969-3-实拍VPN组网页渲染截图` 沉淀，2026-09-07）

> 直接动因：VPN 组网页导航实测发现 Tauri+WebView 装机的 uiautomator dump 与原生 App 认知
> 不同——**层级树恒含全量 DOM 文本**，隐藏节点 text 在档但 bounds=[0,0]。凭「dump 里有文本」
> 判可达、或跨状态复用坐标 tap，都会翻车。上游证据：`test-artifacts/ui-real/
> evidence-vpn-969-1.txt`（全程命令+输出零节选）、`evidence-vpn-969-uidump-{main,drawer}.xml`、
> review/deliverable.md §1-§2（bounds 与 tap 坐标逐点对照，判官 PASS 2026-09-07T11:41:45Z）。

1. **文本在 dump ≠ 视觉可见/可点**：WebView 的 dump 层级树含全 DOM 文本——抽屉折叠未展开时
   六项菜单+退出登录的 text 全部在档，但 bounds 一律 `[0,0][0,0]`（未布局，本块 evidence §1
   实测）。判据：**可见性看 bounds 非 [0,0]，可点性以「bounds 真实+截图目检」双证**；text
   检索只支撑否定性结论（零命中），命中本身不构成可达/可见证明。
2. **bounds→中心点现算，一状态一 dump**：`bounds="[x1,y1][x2,y2]"` → 中心
   `((x1+x2)/2,(y1+y2)/2)`。本轮实例（1080x2400）：底部「消息」Tab `[49,2278][543,2378]`→
   tap 296,2328；「打开我的资料」`[42,157][147,267]`→tap 94,212；抽屉**展开后**「设置」容器
   `[28,1480][779,1619]`→tap 494,1583。展开动作（tap 头像）后必须**重新 dump** 取真实 bounds，
   禁用上一状态坐标（[0,0] 隐藏态坐标 tap 无效）；每步操作后 dump/screencap 验证界面迁移。
3. **负结论的 dump 证据力自检（正对照）**：主张「dump 全文零 X」前，先 grep **当前路由专有
   文本**证明 dump 确随路由变化（本轮设置页：`grep -cE '外观|主题设置|存储与数据|账户与安全|NFC'`
   = 6 命中 + VPN 零命中）——正对照成立，零命中才有证据力；否则「零命中」可能只是 dump 失效
   （本轮 review §2 即以此法独立核验 dump 证据力并获判官认可）。
4. **过渡态与滚动折叠区**：动作后 `sleep 2 && uiautomator dump` 取稳定态；「入口可能在折叠区」
   用 `input swipe` 滚动后 dump diff 复验（本轮：滚动前后文本节点 diff 空=零新增），排除漏看。
5. 与 §2 已知坑③的关系：§2 管「跨轮禁抄历史坐标」，本节增「**同轮内跨状态也禁复用坐标**」——
   状态（抽屉开合/页面路由）变了，dump 必须重取。

## §9 渲染态 vs 功能态：区分记录格式与「页面不可达/功能未就绪」留证口径（块 `1788779617969-3` 沉淀，2026-09-07）

> 直接动因：VPN 组网（HuanvaeGuard）页在移动端装机**无入口不可达**（桌面端入口存在但移动端
> 布局不含+平台门控 return），按卡面预置决策点 V-1/V-2 如实记 FAIL 获判官 PASS——「页面拿不到」
