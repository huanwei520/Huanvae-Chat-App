VERSION=1.1.28
MESSAGE=手机端点【别人】头像打开的资料页：补上左边缘侧滑返回（此前只有「我自己的资料页」有，huanwei 说的那个入口从没接过），并堵住整页可被横向拖走停在偏移位的洞（真因是 overflow-y 隐式带出 overflow-x，非手势问题）+ 桌面端更新进度条不再「卡 0% → 突然完成」（真因是分片下载器用 resp.bytes() 等整片下完才累加，200ms 上报器读到的恒为 0；改流式逐块累加并补重试回滚，避免重复计数冲过 100%）+ 【安卓补上分片并发下载】—— v1.1.23 那次 8 段分片只改了桌面，安卓 download_apk 一直是单连接顺序流，这是「手机端下载极其缓慢」的直接根因；安卓版按偏移直接写盘（不照搬桌面的整片驻留内存，APK 120MB+ 会 OOM），保留原有进度事件与完成收尾，探测不到 Range/包小于 4MB/分片失败一律回退单连接+ 会话内查找新增「群成员」分类：可单独查看某个群员在本群的聊天记录，与文字/图片/视频/文件四分类正交+ macOS 视频消息不再只显示灰块：改走本地 HTTP 媒体服务器（127.0.0.1，自带 Range/206），绕开 WKWebView 不把 Range 头交给自定义协议处理器的限制（WebKit Bug 203302）—— 与安卓当年绕开 asset:// 是同一条成熟路径。已知未做：相册发送侧入口、下载器换成熟方案调研；本版 UI 改动的真机截图待有辅助功能权限的驱动方补齐。
